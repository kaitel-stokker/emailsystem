Note for Design Agency — Dynamic Content

Blocks marked Dynamic / AMPscript are rendered server-side via Salesforce Marketing Cloud at send time — not at design time. Text, images, URLs and element visibility are populated dynamically per recipient or per campaign.

Design must accommodate: variable text length (design for both short and long variants), optional/hidden elements (block must look correct when optional elements are absent), and per-market differences in copy length and asset dimensions.

Please design with content flexibility in mind. Avoid fixed-height text containers. All text areas should expand gracefully.
